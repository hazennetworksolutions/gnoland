## 📋 Overview

Gnoland is a smart contract platform powered by Gnolang (Gno), an interpreted version of Go designed for transparency and composability. Topaz is the testnet that succeeds test13 in the Gnoland rollout — a **fresh chain, not a hardfork**: it builds a new ~2.7 MB genesis straight from the `examples/` tree instead of replaying test13's transaction history, so nodes sync in minutes instead of days and **no balances, realms, or names carry over from test13**.

Validator registration on Gnoland is **GovDAO-based** — validators register by calling a realm (smart contract) and are added to the active set through a governance proposal. This process is permissioned and community-driven.
